WHAT'S IN HERE

One folder. No strings.

Pixels Public Stash is a plain GitHub repo, organized by loot type, that anyone can clone, fork, or drop assets into. No accounts, no paywalled tiers — if it's in the stash, it's yours to use.

Everything is released under a permissive license noted in each folder's README. Credit is appreciated, never required.

HOW TO LOOT

Getting assets into your game

01

Clone the repo

Run git clone on the Pixels Public Stash repository, or download it as a zip from GitHub.

02

Open the loot folder

Each category has its own subfolder with a README listing what's inside and the license it's under.

03

Drag assets into your project

Sprites are exported as trimmed PNGs; tilesets keep their native grid size in the filename.

04

Ship it — and stash something back

Pull requests with new loot are always welcome, credited or anonymous.
